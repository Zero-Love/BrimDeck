新功能
- 收起行「设备最低电量」：MDL2 外设图标 + 电量 %（色阶同本机 Charge）；休眠用 secondary 灰显上次 % +「休眠」（不误报 0%），未知为「··」；多设备只露最低一台；宽度够时可带短型号。
- 「设备」页卡片：图标 + 名称 + % + 在线/休眠；休眠整列约 0.55 透明。
- 灵动岛 QQ 邮箱验证码（#201）：短时收起通知 `[ ✉  {码}  ·  来自 {短名} ]`，点击复制（约 1.2s「已复制」）后恢复；「自动复制」默认关；锁屏/全屏隐藏岛时不弹明文码。

说明
- 本仓库预发布，叠设备页 UI + 黑爵（向上游 #202）与 QQ 验证码（#203 / #201）。勿在 Issue/PR 写入个人邮箱或授权码。
- 充电图标 / DPI / 回报率仍延后。验证码为只读 IMAP + 授权码，不是完整邮箱客户端。
- 设置 → 系统监控的收起读数打开「设备最低电量」。设置中打开 QQ 验证码并在本机填写授权码。
